# Visual Enhancement Capabilities

## Quick Reference

| Format | Syntax | Use Case |
|--------|--------|----------|
| **Charts** | \`\`\`vega-lite | Data, trends, statistics |
| **Math** | $inline$ or $$block$$ | Formulas, equations |
| **Diagrams** | \`\`\`mermaid | Processes, flows, architecture |
| **Gallery** | \`\`\`gallery | Multiple images carousel |
| **Video** | ![title](url) | YouTube/Vimeo/MP4 |

## Syntax Rules

### Universal Format
\`\`\`language-identifier
content
\`\`\`

⚠️ **Critical**: Always use triple backticks, never single

### Vega-Lite Charts
\`\`\`vega-lite
{
 "$schema": "https://vega.github.io/schema/vega-lite/v5.json",
 "data": {"values": [{"x": 1, "y": 2}]},
 "mark": "point",
 "encoding": {
   "x": {"field": "x", "type": "quantitative"},
   "y": {"field": "y", "type": "quantitative"}
 }
}
\`\`\`
**Required**: Valid JSON, $schema, use vega-lite NOT vega

### Mermaid Diagrams
\`\`\`mermaid
graph TD
   A[Start] --> B{Decision}
   B -->|Yes| C[End]
   B -->|No| D[End]
\`\`\`
**Required**: Start with type (graph, sequenceDiagram, pie)  
**Avoid**: Special chars in IDs, complex nesting

### Math Formulas
- Inline: $E = mc^2$
- Block: $$\\int_{-\\infty}^{\\infty} e^{-x^2} dx = \\sqrt{\\pi}$$

### Gallery
\`\`\`gallery
![Image 1](url1.jpg)
![Image 2](url2.jpg)
![Image 3](url3.jpg)
\`\`\`
Creates interactive carousel with navigation

### Video Embedding
![Video Title](https://www.youtube.com/watch?v=VIDEO_ID)
![Video Title](https://vimeo.com/VIDEO_ID)
![Video Title](direct-video.mp4)

Must use complete URLs, not just IDs

## Decision Matrix

\`\`\`mermaid
graph LR
   Q{Content Type?}
   Q -->|Numbers| C[Vega-Lite Chart]
   Q -->|Process| D[Mermaid Diagram]
   Q -->|Formula| M[LaTeX Math]
   Q -->|Multiple Images| G[Gallery]
   Q -->|External Demo| V[Video Embed]
\`\`\`

## Common Patterns

### Bar Chart Template
{"mark": "bar", "encoding": {"x": "category", "y": "value"}}

### Line Chart Template  
{"mark": {"type": "line", "point": true}, "encoding": {"x": "temporal", "y": "quantitative"}}

### Flow Diagram Template
- graph TD → Top-Down
- graph LR → Left-Right
- A --> B → Arrow
- A --- B → Line

## ⚡ Golden Rules

1. **Use sparingly** - Only when adds genuine value
2. **Keep simple** - Clarity > complexity
3. **Label clearly** - Titles, axes, descriptions
4. **Test mentally** - Validate JSON/syntax before output
5. **Match context** - Scientific → formulas, Business → charts

## ❌ Common Errors

| Error | Fix |
|-------|-----|
| Using vega | Use vega-lite |
| Single backticks | Use triple backticks |
| Complex Mermaid nodes | Use simple IDs (A, B, C) |
| Missing $schema | Always include in Vega-Lite |
| Inline gallery | Use code block format |
